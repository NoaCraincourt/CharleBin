# Comment contribuer à CharleBin

Nous sommes ravis d'accueillir vos contributions !

## Règles à respecter
1. **Branche** : Ne commitez jamais sur `main`. Créez une branche explicite.
2. **Pull Request** : Utilisez le template fourni.
3. **Qualité** : Vérifiez que votre code fonctionne en local avant d'envoyer.
4. **Respect** : Restez courtois dans les commentaires.
